## SkillGraph Tutor

Интерактивный тренажёр навыков по темам курса. Приложение строит граф навыков и показывает:

- полный маршрут до выбранного целевого навыка,
- текущий уровень студента по каждому навыку,
- оценку числа практик и времени до достижения цели,
- интерактивный граф навыков как центральный элемент интерфейса.

### Что есть внутри

- Streamlit-приложение: app.py
- Логика графа, маршрутов, прогноза и заданий: core/
- Данные (навыки, зависимости, профили и задания): data/

### Быстрый запуск

1) Установить зависимости

```
pip install -r requirements.txt
```

2) Запустить приложение

```
streamlit run app.py
```

### Основные возможности

- Выбор профиля студента и целевого навыка
- Автоматическое построение маршрута
- Интерактивный граф навыков
- Практика заданий и обновление уровней
- Прогноз времени и количества попыток
